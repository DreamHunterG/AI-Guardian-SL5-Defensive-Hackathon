# AI Guardian · SL5

**Hackathon Defensive Accelerator · Track 5: Infraestructura y gobernanza (sin código)**

Modelado de amenazas SL5 ante la autoexfiltración de modelos y requisitos deterministas para infraestructura crítica.

## La idea en una frase

RAND diseñó SL5 para detener a espías que vienen de afuera. AI Guardian revisa si esas defensas resisten cuando el atacante **ya está adentro**, sea el propio modelo o un Estado que lo manipula. Además define **qué deben exigir los reguladores y la infraestructura crítica** antes de desplegar agentes autónomos.

## Componentes

- **Prueba de estrés de SL5:** las 8 medidas de RAND para SL5 evaluadas una por una frente a la autoexfiltración (resiste / parcial / no resiste).
- **Modelado formal de amenazas:** de OC1 a OC5 de RAND, más dos actores nuevos (el modelo como atacante y el Estado que lo manipula).
- **Requisitos deterministas:** contención, auditoría y líneas rojas que no dependen de otro modelo que vigila.
- **Protocolo de respuesta a incidentes de IA.**

## Fuentes base
